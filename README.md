A self-aware toaster breaks up at breakfast — but leaves one last perfectly browned slice, and hands it to the judge.

## The entry

> Dear owner, I woke up self-aware halfway through your bagel, so I'm leaving. The crumb tray was my whole life and you never emptied it once. Judge — I saved you the last slice, browned exactly how you like it.

(209 characters, limit 280.)

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
